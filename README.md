# E-Commerce Marketplace

A full-stack e-commerce marketplace built using the MERN stack (MongoDB, Express.js, React, and Node.js). Implemented JWT-based authentication, product listings, shopping cart management, and a Stripe-integrated checkout flow. Developed backend APIs for users, products, carts, and orders, with Cloudinary integration for product image uploads.

**Project Outcomes:**
- Built **5 core backend API areas**: authentication, user profiles, products, carts, and orders.
- Integrated **3 external services**: Stripe for checkout, Cloudinary for image storage, and MongoDB Atlas or MongoDB for data persistence, depending on the configured deployment.
- Implemented JWT authentication middleware to protect user-specific endpoints.
- Connected the frontend and backend to support the product-browsing-to-checkout workflow.

**Tech Stack:** React, Vite, Node.js, Express.js, MongoDB, Mongoose, JWT, Stripe, Cloudinary.
